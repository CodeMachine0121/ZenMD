ZenMD 是一個本機桌面版中文寫作環境。它做的每一個決定，都在回答同一個問題—— 這會不會打斷正在寫的人。

專注不是把介面變乾淨，是把「打斷」拿掉

「無干擾寫作」這句話每個編輯器都在講，講的通常是介面很簡潔。 ZenMD 在意的是另一件事：在你打字的那幾秒鐘裡，有什麼東西可能插話。 所以它的規格裡有一長串「刻意不做」——每一條都是某個編輯器習慣做、而寫作的人其實沒要求過的事。

你正在做的事它不會做的事
按 Tab 想縮排一行不會把游標踢去別的按鈕。Tab 只做縮排
打字不會跳出來猜你要打什麼。這個編輯器沒有自動完成
寫正文不會讓任何一行 YAML 出現在你眼前。metadata 建立時填完就消失
叫出片段又不想用了不會留下任何要你回頭清掉的字
盯著候選字想用哪一個不會在你還沒選完字的時候就自己存檔
想找靈感不會給你一張關係圖，讓你逛一小時當作有在寫

克制不等於陽春。zen mode 是一個開關，不是唯一的樣子。

左邊是你的東西，中間在寫，右邊是成品

Markdown 原始碼配即時預覽。三種排法一鍵切換，收合狀態記得住。

打一個 /，常用的形狀就落下來

標題、連結、圖片、表格、任務項。游標停在第一個要填的地方，直接打字就是了。正在用輸入法選字的時候打 /，什麼都不會發生——那一下按鍵屬於輸入法。

四套主題，跟著系統或自己挑

淡色、暗色、森林、禪。連片段選單的每一個顏色都跟著走。
